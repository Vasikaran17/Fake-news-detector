About the Project

Architecture, evidence synthesis, and continuous learning methodology behind the Fake News Detector.

What is Live Fake News Verification?

Traditional fake news detection systems rely solely on static classifiers trained on historical datasets. While statistical models excel at recognizing stylistic patterns (such as sensationalist syntax or emotional hyperbole), they cannot know whether an emerging claim that occurred this morning is factual.

This project implements a hybrid verification architecture: it combines an NLP & Machine Learning statistical model with real-time evidence retrieval from established news organizations and verified fact-checking organizations. Claims are cross-referenced against live coverage to determine whether available evidence supports, contradicts, or leaves the claim uncertain.

Safe Continuous Learning Architecture: Unverified live articles are never blindly used as training labels. The ML model's own predictions are never used as ground truth for retraining. Only independently verified records from authoritative fact-checking feeds enter the continuous learning dataset.

Verification Result Classifications

How evidence translates into system verdicts:

REAL

Available reliable evidence supports the claim. Multiple independent news sources corroborate the reported events.

FAKE

Available reliable evidence contradicts the claim. Verified fact-checking organizations or official reports refute or debunk the assertion.

UNCERTAIN

Available evidence is insufficient or conflicting. Crucially, no evidence is not automatically evidence of falsity.

Viva & Demonstration Guide

Academic defense concepts for B.Tech evaluation:

Q1: Why not simply retrain the model on every live article collected?

A live news article by itself does not provide a ground truth REAL/FAKE label. If a system automatically uses its own predictions or unverified headlines as training labels, it introduces confirmation bias and catastrophic self-reinforcing errors. Batch updating using only independently verified fact-check datasets ensures model integrity.

Q2: What is the role of the Machine Learning model in this system?

The ML model acts as a stylistic and linguistic prior (trained with TF-IDF and Logistic Regression on 34,000+ benchmark articles, achieving 98.14% baseline accuracy). However, for real-world claims, live evidence cross-checking takes precedence. If live evidence is insufficient, the system outputs UNCERTAIN rather than forcing an ungrounded prediction.

Q3: How does the system handle duplicate news articles?

The database enforces uniqueness on source URLs, normalizes headlines (lowercasing, punctuation stripping), and computes text overlap so repeated wire reports from syndicated feeds do not create duplicate records.

Q4: How does model versioning work?

When the continuous learning threshold is met (e.g. 50 verified records), the pipeline retrains a candidate model, compares test accuracy/F1 against the active model, and stores the artifact under models/archive/model_v{N} with full metrics in SQLite before promoting it to models/current.
