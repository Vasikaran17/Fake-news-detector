Please provide a CSV file containing verified news records. The system will extract TF-IDF linguistic features and fit a Scikit-learn Logistic Regression classifier.

Expected CSV Structure:

The dataset must contain the following column headers (case-insensitive):

text | label
  • text: The full news article content or headline to analyze.
  • label: Must specify REAL or FAKE.
  • File Size Limit: Extended to support datasets exceeding 600 MB (up to 1.5 GB) with parallelized processing.
